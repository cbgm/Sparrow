# Reporting a security vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Use [GitHub's private vulnerability reporting](https://github.com/cbgm/Sparrow/security/advisories/new) to contact the maintainers privately. Include the affected component, impact, steps to reproduce, and any suggested mitigation. Avoid including real user data, credentials, or live secrets.

If private reporting is unavailable, contact the repository owner privately through GitHub and ask for a secure reporting channel. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.

Sparrow is beta software and has not completed an independent security audit. Please do not use it to protect information whose exposure could put people at risk.
