# Release documentation audit — 2026-10-08

This audit was produced from the supplied release source archive `Sparrow(20261008-124214).zip`.

## Major client changes reflected in this documentation

- Kotlin/Compose/AGP/Koin/Room/Ktor dependency versions updated from the version catalog.
- module graph now contains 47 modules, including `:core:base`, `:protocol`, `:feature:embedding`, `:feature:notification`, `:feature:applock` and `:feature:polls`.
- shared message content moved to the `:core:base` `MessagePartDto` / `MessagePart` / `MessagePartUi` hierarchy.
- image and video are separate message-part variants; voice and poll are part of the same hierarchy.
- database schema is version 54; structured part payload moved into `MessagePartEntity.payload` through `MessagePartPayloadMigration53To54`.
- general `OperationMessage` now covers edit/delete/reaction/poll vote/poll close.
- group polls are wired end-to-end through composer handoff, group sending, operation updates, voters UI, expiry countdown and pinned-message rendering.
- poll expiry is duration-in-minutes input converted to an absolute timestamp; effective close is derived with `PollPolicy.isClosedAt(...)` rather than a background automatic close operation.
- task-based startup is implemented through `ApplicationStartupRunner`, `StartupTask` and the concrete task list in `ApplicationStartupTasks.kt`.
- `:feature:applock` adds settings-controlled device-owner authentication.
- pinned messages support poll rendering and detached nested poll-image loading.
- media/attachment documentation now describes cache-path propagation and receiver-side refresh requirements.

## Verification performed

The documentation inventory scanned the full extracted source tree, `settings.gradle.kts`, module build files and Kotlin declarations. `docs/generated/` was regenerated from this source snapshot.

A full Gradle documentation/build verification was **not** run in the isolated environment because Gradle 9.6.1 was not available locally and external download was unavailable. The package therefore does not claim a successful Gradle build.
